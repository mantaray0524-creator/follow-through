# follow-through

让 agent 记住还没收尾的事，定时核实，有新变化才找你，而且每次只带一个现成动作。它交付给你的东西也会先自查，交付后再复查一次，有证据才算闭环。

追踪、巡检、自查三合一，学术和生活场景都能用。有知识库（比如 llm-wiki）的话，存进去的东西会和追踪清单关联起来，能用上时它会来找你。

## 安装（让你的 agent 照做）
1. 把仓库下载到它的工作区，比如 `git clone <本仓库地址> followthrough`
2. 把 `templates/` 里的三个文件复制到 `followthrough/` 目录，然后填好 `CONFIG.md`。**"试行开始日期"填安装当天的日期**。
3. 读完 `SKILL.md`，把它学成你自己的 skill，存进你的 skill 目录。
4. 用你自带的定时任务每天触发一次巡检，并让它运行时加载这个 skill。已经有早报的，就并进早报，不要另开一个。
5. 先试行 3 天：候选只写日志，不推送。**第 4 天它会主动发一条复盘问你"这条准吗"**，你回"准"就正式开始推送。

## 文件
- `SKILL.md`：完整规则
- `templates/`：配置、追踪清单、日志的模板
